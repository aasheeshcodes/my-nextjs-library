# Component: Hero

## What it does
Full viewport hero section with badge, heading, subtext and CTA buttons.

## Features
- Responsive centered layout
- Highlight color on heading
- Primary + Secondary buttons
- Easy to customize text and colors

## Colors
- Background: #0f0f1a
- Highlight: #e94560
- Subtext: #a0a0b0
