# Component: Footer

## What it does
Full footer with brand, navigation links, resource links and copyright.

## Features
- 3 column layout (brand + 2 link groups)
- Dynamic year using new Date()
- Responsive with flexWrap
- Divider line between top and bottom row

## Colors
- Background: #1a1a2e
- Logo: #e94560
- Links: #a0a0b0
